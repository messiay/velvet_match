⚙️ How the matching algorithm works

Weighted Compatibility Scoring — each of the 12 questions carries a different weight (6–11 pts). For each pair of people, we compute a score:

  • Same-mode questions (e.g. date style, texting, affection): exact match = full weight, 1-apart = 62%, 2-apart = 22%
  • Balance-mode questions (energy, pace): complementary answers (1 apart) = full weight, exact = 82%, opposite = 55%

The raw score is divided by max possible score → a 0–100% compatibility number.

Global Optimal Pairing — we don't just pair each person with their personal best match. We run a recursive algorithm that finds the set of pairs maximising total compatibility across the whole room. This is a brute-force best-matching for small groups (<30 people) — elegant for an event, accurate for the numbers involved.

If there's an odd number of guests, the leftover person is added as a "best-fit trio" to whichever existing pair scores highest with them.
